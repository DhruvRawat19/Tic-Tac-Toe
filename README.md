# Tic Tac Toe

A classic two-player Tic Tac Toe desktop game written in Java. The game presents a 3 x 3 grid using Java AWT and alternates moves between **O** and **X**.

## Features

- Graphical 3 x 3 game board
- Two-player turn-based gameplay
- Blue markings for player O
- Red markings for player X
- Automatic winner detection for rows, columns, and diagonals
- Cells become disabled after a move

## Requirements

- Java Development Kit (JDK) 8 or newer

## Run the game

From the project directory, compile and run:

```bash
javac TicTacToe.java
java TicTacToe
```

The game window will open on your desktop. Players take turns selecting an empty square; the program announces a winner in the console when three matching marks form a row, column, or diagonal.
